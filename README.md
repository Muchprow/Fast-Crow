# 🐦 Fast Crow

**Fast Crow** is an ultra-fast string processing and cleaning library for Python, written in pure **C** using the CPython API.

The main goal of the project is to speed up routine string operations by executing calculations at the native machine code level.

## 🚀 Key Features

* **C Speed:** Performs string manipulation significantly faster than pure Python implementations.
* **Lightweight:** Zero heavy dependencies — just clean C-code under the hood.
* **Simple API:** Clean and straightforward Python interface.
